Penjaga Karang (Reef Guardian): an original canvas shooter. Pilot a guardian crab, pop waves of junk jellyfish-bots with bubble shots, grab power-ups, beat the mini-bosses on waves 5 and 10, and keep the reef alive through all 10 waves.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
